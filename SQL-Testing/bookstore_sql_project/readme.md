# Book Store SQL Testing Project

## Overview

This project demonstrates database testing using SQL queries for a Book Store application.

The main goal of the project is to verify data integrity, validate database operations, and test different scenarios using SQL.

## Project Scope

The following database operations were tested:

- Data retrieval using SELECT queries
- Filtering and sorting data
- Data validation
- Insert, Update and Delete operations
- Testing different database scenarios and edge cases

## Database

Database Management System:
- Microsoft SQL Server

Tool Used:
- SQL Server Management Studio (SSMS)

## Testing Activities

The project includes:

- Database structure analysis
- Test data preparation
- SQL query execution
- Validation of expected results
- Identification of data-related issues

## SQL Concepts Used

- SELECT statements
- WHERE conditions
- ORDER BY
- JOIN operations
- Aggregate functions
- INSERT / UPDATE / DELETE queries
